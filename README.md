# Quiz Formazione AI

Questionario finale del corso di formazione sull'intelligenza artificiale:
20 domande su LLM, prompting, privacy e AI Act.

Il partecipante inserisce nome e cognome, risponde dal telefono e vede subito
punteggio e correzione completa. L'app è un unico file HTML: gira interamente
nel browser, senza server e senza limiti al numero di persone collegate
contemporaneamente. Nessun dato lascia il dispositivo.

**Online:** https://uchezzo.github.io/quiz-formazione-ai/
